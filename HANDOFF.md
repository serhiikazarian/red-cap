## How to resume
0. (Bundle of 31 Oct 2026, state 11.3.) The folder is a git repository with every version tagged (`v1.0`, `v10.4` … `v11.3`; `patch112.py` reads `v10.4`). Rebuild with `cd game && python3 build2.py` and check `sha256sum game/red-cap.html` against `V11.3.sha256`. Frozen copies included: `game/red-cap-v1.0.html` (Serj's release) and `game/red-cap-v11.3.html` (current).
1. Unzip anywhere and run `bash setup.sh` (links `/home/claude/work` to the folder, which every test script uses; installs Python Playwright 1.63 and the node tools).
2. Edit **`game/src3.html`** (the source). Never edit `red-cap.html` by hand — it is generated.
3. Build: `cd game && python3 build2.py` → writes `red-cap.html` (~4.6 MB; base64 webp assets + shapes.json inlined at `/*ASSETS*/` and `/*SHAPES*/`, and since v43 the fonts as `@font-face` rules at `/*FONTS*/` from `assets2/fonts/`; since v45 recorded sounds at `/*SOUNDS*/` from `assets2/sfx/*.mp3`; since 8.8 three.js r128 itself at `/*THREE*/` from `vendor/package/build/three.min.js`, ~5.4 MB in all: the game needs no network).
4. Smoke test: `python3 tests/boot.py` (expects `[]`; before v43 it showed one `ERR_FAILED` for the blocked Google font, which is no longer requested).
5. Regressions: `python3 game/test22.py` and `game/test10.py` (current). `game/test17.py` needs `test16.py`, which is not in the bundle. v21 probes in `tests/v21_*.py` (hero edge close-up, yo-yo string + catalogue, keep-out overlaps, draw calls over many views, combat, profiler, view comparisons); most take the build path and an output folder as arguments.
6. Publish to the **same** artifact URL (pass `url` from a new chat; read it first), then copy to `red-cap-v8.N.html` and send it.
7. Regressions to run after any change (one browser at a time): `tests/boot.py`; `game/test10.py`, `game/test22.py` (from inside `game/`); `tests/` probes `v38_cover` (takes an output folder too), `v39_jester`, `v42_yoyo`, `v43_transition`, `v45_sounds`, `v46_words`, `v48_brainless`; `tests/v50_soak.py build 60` (memory over three floors with restarts). Probes take the build's **absolute** path. Then prettier (no changes) and eslint (clean) on the extracted game script (`tools/README.md`).

## Working conventions (keep these)
- Changes go in as small python patch scripts with `rep(old, new, count=1)` that assert exact match counts; back up `src3.html` first.
- **Since v35 the game script is prettier-formatted** (`tools/.prettierrc.json`: 150 columns, single quotes, one statement per line). Take `rep()` anchors from the formatted text. After a purely cosmetic edit, prove nothing changed with `tools/astsame.js` (same syntax tree). The top of the script has a table of contents and the map legend; banners (`/* ---------- section`, `/* ----- sub-section`, `// ===== Enemy`) mark the rest. `tools/README.md` lists the node tools (prettier, acorn, eslint config, dead-code finder).
- **Never put a `// comment` in the middle of a line that continues with code** — it swallowed code twice. Use `/* */` inline.
- GLSL: don't name uniforms/variables `flat`, `smooth`, `in`, `out`, `sample` etc. (WebGL2 / GLSL 300 es keywords → shader silently fails). `smoothstep(a, b, x)` needs a < b.
- `e.mats` get their `.color` reset to white every frame (hit flash). Coloured parts must use textures or vertex colours, not material colour.
- Shared geometry/materials: `share()` (never disposed); `still()` → static matrices; textures owned per level go in `OWN` (`own(t)` marks one). `clearLevel` frees what is still in `G.group`; anything removed for good mid-floor goes through `discard(o)` (frees its own geometry and `OWN` textures; materials are left to the garbage collector, because disposing the last material of a kind destroys its shader program). A shape made again and again mid-fight is made once and `share()`d. `paper(name, h, depth, lit, once)`: `once` for a one-off size (onlookers' random heights), which must not go into the shared shape cache.
- Sound: synthesised `sTone` / `sNoise` / `SFX.*`, and since v45 recorded clips: `sPlay(name, gain)` → `{ s, g }` (or null before decoding; `AU.buf` is filled by `auInit` on the first click). Add a clip by dropping an mp3 into `assets2/sfx/` (its name without `.mp3` is the key); `assets2/sfx/README.txt` records how each was made from `originals/`.
- Helpers: `paper(name,h,depth,lit)` cutouts from shapes.json, `mergeGeos([[geo, M4(...)]])` (keeps uv + vertex colours), `M4(x,y,z,rx,ry,rz,sx,sy,sz)`, `bloodPool()` (returns mesh), `burst`, `floatWord`, `toast`, `sTone`/`sNoise` synth, `SFX.*`.
- Map grid `CELL = 3`; `solid()` ('#', 'g' while `G.gateClosed`); raised floor `LIFT = 1.5` (things built inside a raised cell are lifted automatically — don't add height twice).
- **Since v39 (reworked in v43) the menu buttons and the exit door enter a floor in steps** (states `'leave'` → `'build'` → `'intro'`, about 0.8 s at least). A test that clicks `#startBtn` must then `await pg.wait_for_function("state === 'intro'")` (all bundled tests do). Plain `startGame()` / `enterFloor(i)` calls still build at once.
- Lint is clean since v43 (`/* global ASSETS, SHAPES */` at the top of the game script; `grumpCover` is marked as kept for test22): `npx eslint` should print nothing.
- Headless testing: Playwright + swiftshader, viewport 880×500, `frame = () => {}`, step with the `SIM` string from `test10.py` (it does not run `G.anim`; tests that need it append the call). First render of new shaders is slow (tens of seconds). Grain CSS compositor animation crashed swiftshader — keep the background-position version.

- **`still()` now means "baked"**: `bakeStatics()` (end of `buildLevel`) removes every still, opaque mesh (and transparent ones whose material is marked `flat()`) and merges them into one mesh per material look. Never keep a reference to a still mesh to change it later; leave such things unmarked.
- Random set dressing must pass `clearOf(x, z, r)`; story things claim ground with `keepOut(x, z, r)` (`storyGround()` lays down the map's story cells and talkers).
- Particles, blood drops, drips, pages, motes and birds are `InstancedMesh` pools (`instPool`, `PMESH`, `BLOOD`); F3 block props and box-shaped floaters are instanced by texture (`instanceProps`, `syncBoxes` after any change).
- Red Cap's cards use `markInk` blending (clears render-target alpha) and `featherEdge`; the post pass skips ink near alpha-cleared pixels, and `inkCard` gives him his own smooth outline. Grain and vignette live in the post shader now (no `#grain` / `#vig` layers).
- HUD elements are cached in `EL`; write to the DOM only when a value changes.
- **Since 8.1: see-through things.** Anything that can stand between the camera and the fight is registered while the floor is built with `seeThru(o, dyn, how)` (since 10.0 onlookers and easels only keep the camera off: see below) (pillars, fangs, totems, F1 easels, F3 cover blocks, onlookers, F1's floating faces; every `G.deco` floater is added by `seePrep`). A new big prop or floater should be registered too, or the camera can sit inside it. `seePrep` (after `instanceProps`) gives each a shape: a standing column from its box, spheres per part for moving ones, a true box for an instanced floating box. `bakeStatics` bakes each see-through thing on its own (`lookKey|seeN`), so it can fade alone. Faded = material clones (`transparent`, no depth write; alphaTest scaled once to a fixed value so no new shader mid-play) and layer 1; instanced boxes are hidden (`it.see` stand-in mesh, `syncBoxes` writes a zero matrix for them); `shedBox` marks `it.shed`. The contour is a half-size mask (`seeRT`, `seeMask`: layer 1, `SEE_MAT` override) read by the ink pass (`tSee`, `seeOn`). `seeWarm` in `warmUp` builds the faded shaders behind the card.
- **Since 8.1: sound sources.** `AU.at` is where the sound being made comes from; the frame loop sets it to each enemy's position around `updEnemy`, and `sTone` / `sNoise` / `sPlay` scale by `auK(AU.at)`. `hurtHero` clears it, so Red Cap's own sounds never fade. A long clip that should follow its source keeps `.at` (see `sprayNode`, `sprayFollow`).

- **Since 8.5: loading does real work.** `warmUp` pre-draws `WORDS_SEED` + `WORDS_FLOOR[floor]` + words used this session; `calibrate()` (scrap path only) times real frames under the ink and lowers `resScale` to `CAL_MS` 13 ms; on floor three also the fog wall and a full smoke cloud to `CAL_HEAVY_MS` 18 ms; the scrap stays ≥ 0.7 s (≥ `FINAL_SCRAP_MS` 3 s before floor three) and the scissors cross it once.
- **Since 12.0:** pillars have their thick contour again (11.8's ground mask pass); pyramids have none (`SOLID[kind].line`), fade 1.5× slower (`.slow`), keep writing depth while faded (no flash at the solid/faded switch), and their halo/pool draw before see-through things (`renderOrder` -1). (11.9 had removed all ground contours; that note is superseded.) **See-through sorting:** `renderer.setTransparentSort` draws far to near as three.js does, but a figure of parts in a set order (a Grin: `userData.sortRank`, `sortZ` from `sortUnits()` each frame) sorts as one thing; never give a see-through part a global `renderOrder` > 0 again (words keep 10: always on top).

## Game structure
- Floors: 1 *The Usher's Corridor*, 2 *The Mouth* (deco `mouth`: bear traps on 'o', fangs on 'T', ramps), 3 *Stop Talking Shit* (deco `blocks`: Grump, cover blocks, Jester chamber behind row 8, hidden boss).
- Enemy types: B Usher, G Grin, R Priest (+ghosts), U Grump, M Jester, q Shade, L Living / Dying (hidden boss: whole → hair, eyes, jaw, skull), Y Geezer, Z Bruno, W/S Smoker / Brainless the Second.
- Hero: hearts (whole hearts, 1–2 per hit), yo-yo (1,2,3 rhythm; third throw ×1.8; reach 3.8 / 4.5 m, stretched up to 1.2 m to a soft-locked target since v42), slingshot pebbles, dodge, mask pickup.
- End: Jester finale (slow-mo, flash, huge mask pickup ends the game), post-game screen with stats, deaths and the catalogue (left/right pages, localStorage `redcap.catalogue.v1`).
